# Oxide Engine

A Rust + [Bevy](https://bevyengine.org) reimplementation of Friday Night Funkin'
(V-Slice) at content parity, with bundled optimized assets and Ruby (mruby)
modding.

- Single verification command: `cargo xtask verify`
- Milestone plan and gates: see the project plan (internal documentation).
- Agent instructions: [`AGENTS.md`](AGENTS.md).

Status: early milestones. The `oxide` binary exists; most subcommands report
`not implemented yet`.
